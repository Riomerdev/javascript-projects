# Subscription Portal

Portal de operaciones para revisar cambios de suscripción antes de confirmarlos. Permite elegir plan y cantidad de licencias, ver el prorrateo de días restantes y registrar una modificación en el navegador.

**Lenguaje:** JavaScript  
**Caso de uso:** reducir errores al cambiar el plan de una cuenta durante un ciclo de facturación.

## Ejecutar

Abre index.html desde un servidor estático local. Cambia plan o licencias para revisar el importe inmediato y el próximo cobro. La confirmación se guarda localmente como demostración.

Los importes son ficticios y no se realiza ningún cobro. El prorrateo usa centavos enteros y un ciclo de 30 días para evitar errores de redondeo en números binarios.
