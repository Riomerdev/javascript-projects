# Shipment Tracking

Panel de seguimiento para operaciones de última milla. Permite buscar por guía o destino, filtrar estados y revisar eventos con hora local, zona operativa y ETA. El conjunto de datos es ficticio y se sirve desde JSON local.

**Lenguaje:** JavaScript  
**Caso de uso:** priorizar despachos demorados durante un turno de distribución.

## Ejecutar

Abre index.html desde un servidor estático local. Usa los filtros de estado, busca una guía como BR-88421 y abre una tarjeta para revisar su historial.

El proyecto es una interfaz de demostración con datos sintéticos; no consulta mapas ni ubicación real.
