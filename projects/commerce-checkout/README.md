# Commerce Checkout

Flujo de compra para un comercio que vende equipo de protección. Incluye catálogo, carrito persistente, validación de dirección, cálculo en centavos, cupón, resumen de impuestos y pago en modo simulado.

**Lenguaje:** JavaScript  
**Caso de uso:** revisar un checkout completo sin conectar una pasarela ni mover dinero real.

## Ejecutar

Abre index.html en un servidor estático local. Agrega productos al carrito, usa el cupón FIELD10 y completa el formulario. El pedido queda guardado en localStorage. El botón de pago solo simula la respuesta del proveedor; no procesa cobros.
