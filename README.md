# JavaScript Projects

Portafolio de herramientas web y Node.js en **JavaScript**. Cada solución cubre un flujo operativo distinto y trae una guía de ejecución propia.

| Proyecto | Uso | Tipo |
|---|---|---|
| FieldAudit PWA | Inspecciones de campo sin conexión | PWA offline-first |
| Commerce Checkout | Carrito, validación y pago simulado | Aplicación web |
| Support Console | Atención en tiempo real con historial | Node.js + WebSocket |
| Webhook Observatory | Inspección segura y replay local de webhooks | Node.js |
| Shipment Tracking | Seguimiento operativo de envíos | Dashboard web |
| Subscription Portal | Cambios de plan y prorrateo | Aplicación web |

## Automatización

GitHub Actions valida la sintaxis de los archivos JavaScript al abrir cambios y al actualizar main. Los pagos y las entregas externas de las demos son simulados o locales; no se incluyen credenciales ni datos reales.
